# IMovies – Movie Ticket Booking System

## Project Overview
IMovies is an online movie ticket booking platform that allows users to browse movies, view showtimes, select seats, and book movie tickets conveniently.

## Features
- User registration and login
- Browse available movies
- View movie details and showtimes
- Select seats for a movie
- Book movie tickets
- Manage bookings

## Technology Stack
- Frontend: React.js, HTML, CSS, JavaScript, Bootstrap
- Backend: Node.js and Express.js
- Database: MongoDB
- Authentication: JSON Web Token (JWT)

## System Requirements
- Node.js and npm
- MongoDB or MongoDB Atlas
- Visual Studio Code
- Modern web browser
